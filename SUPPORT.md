# KAYVRA Support

Thank you for using or exploring KAYVRA projects.

## Where to Ask for Help

Before opening a support request:

1. Read the repository README and installation or usage documentation.
2. Search existing Issues for the same question or problem.
3. Check the project's release notes and known limitations, where available.

For a reproducible, non-sensitive bug, open an Issue in the relevant repository and include:
- The project version or commit.
- Operating system and relevant environment details.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Sanitized error messages or logs.

For a feature idea, explain the use case, expected outcome, and why it would help the project.

## Security Issues

Do not use public Issues for vulnerabilities, exposed credentials, or security incidents. Follow [SECURITY.md](SECURITY.md) and use a private reporting route.

## Confidential and Personal Information

Do not post passwords, access tokens, private keys, personal information, client data, production logs, or digital-forensic evidence.

## Scope of Support

Support is provided through the documentation and public project channels made available for each repository. A public repository does not imply a service-level agreement, guaranteed response time, or commercial support commitment.

For project-specific questions, follow the instructions in that project's README.
